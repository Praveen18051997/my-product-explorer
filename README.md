# Product Explorer Dashboard

## Overview
A frontend dashboard built with Next.js App Router, TypeScript, and Tailwind CSS.
The application fetches products from a public API and allows users to browse,
search, filter by category, view product details, and manage favorites.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Data Source
- Fake Store API: https://fakestoreapi.com/products

## Features
- Product listing displayed in a responsive grid
- Search products by title (client-side)
- Filter products by category
- Product detail pages using dynamic routing
- Favorites feature with persistence using localStorage
- Loading and error states for API requests
- Mobile-first responsive design
